# Learning Management System (LMS)

A modern, responsive Learning Management System website featuring online courses, video tutorials, a structured learning journey, and student support. Built using HTML5 and CSS3.

## Features

- **Home:** Introduction, hero section, and five-step learning journey.
- **Courses:** Nine video tutorial cards covering popular technologies.
- **Contact Us:** Contact information and a student message form.
- **Responsive Design:** Layouts optimized for desktop, tablet, and mobile screens.
- **Consistent UI:** Shared navigation, typography, colors, and components.

## Technologies Used

- HTML5
- CSS3
- CSS Grid and Flexbox
- YouTube video embeds

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or run it using the **Live Server** extension.
4. Use the navigation menu to explore the Home, Courses, and Contact Us pages.

## Deployment

This static website can be hosted free using **GitHub Pages**:

1. Push the project to a public GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.
5. Save and wait for GitHub Pages to publish the website.

## Notes

- The contact form is a front-end demonstration and does not send or store messages.
- The Sign In link is a visual placeholder.
- YouTube videos require an internet connection.
- No JavaScript, backend, database, or authentication is required.
